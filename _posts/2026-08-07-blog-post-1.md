I finally got around to building a real website this week, so here's the first post — mostly a note to future me.

Between starting my M.S. at UCSD this fall and juggling a few research projects and an internship, my work was scattered everywhere: publications in random PDFs, talks in old Drive links, code across a dozen repos. I wanted one place that actually tied it together.

I went with [Academic Pages](https://github.com/academicpages/academicpages.github.io), a Jekyll template built for exactly this — publications, talks, teaching, a portfolio, a CV, all as plain Markdown files hosted free on GitHub Pages. No database, no hosting bill, and if I ever break the CSS, my content's still safe in the repo.

Most of the actual work was just organizing: writing front matter for every paper and talk, figuring out that a poster presentation and a peer-reviewed paper probably shouldn't live in the same bucket, that kind of thing. I also managed to name my repo wrong and spend twenty minutes confused about why my site wasn't loading at the URL I wanted — turns out GitHub only gives you the clean `username.github.io` address if the repo name matches your actual username. Obvious in hindsight.

More to come as new papers and projects land. For now, it's nice having a home base.
